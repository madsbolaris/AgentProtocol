## What is the Client SDK?

The Agent Protocol Client SDK provides libraries for Python, TypeScript, and C# to interact with Agent Protocol-compliant servers. Build AI-powered applications with:

- **Simple completions** - Get responses with a single line of code
- **Streaming** - Real-time token-by-token responses
- **Persistent conversations** - Maintain context across multiple turns
- **Tool execution** - Allow agents to call your functions
- **Multimodal content** - Work with text, images, audio, and video
