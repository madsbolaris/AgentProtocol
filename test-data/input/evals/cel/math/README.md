# CEL Math and Edge Case Tests

Mathematical operations and edge case handling in CEL.

## Test Files

- **58-cel-score-math.xml** - Score calculations and mathematical operations
- **60-cel-edge-cases.xml** - Edge cases including null handling, division, overflow

## Purpose

Validates CEL's handling of:
- Arithmetic operations on scores
- Mathematical edge cases
- Null and undefined values
- Boundary conditions
