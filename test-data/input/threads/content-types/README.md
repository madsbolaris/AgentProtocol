## Purpose

These files validate:
- Content type serialization and deserialization
- MIME type handling for media files
- Rich content rendering (adaptive cards, UI elements)
- System event propagation
- Function calling protocols
- Message lifecycle operations

## Testing Focus

- **Media handling** - File URLs, MIME types, size limits
- **Rich content** - Adaptive Cards JSON structure, UI elements
- **Function calls** - Call-id matching, argument serialization
- **Message operations** - Reactions, edits, deletions
- **System events** - Event propagation, filtering
- **Specialized types** - Search results, traces, hosted resources

## Content Type Categories

1. **Input Content** - Content that can be sent to agents (text, images, files)
2. **Output Content** - Content that agents can produce (text, thinking, function calls)
3. **System Content** - Content generated by the platform (events, filters)
4. **Operational Content** - Content for message operations (reactions, edits)
