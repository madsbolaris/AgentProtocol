# TypeScript API Reference

Complete API documentation for TypeScript Hosting SDK.

## Overview

The TypeScript Hosting SDK provides a type-safe, fluent API for building AI agents.

---

## Installation

=== "TypeScript"
    ```bash
    npm install @microsoft/agents-hosting
    ```

---

## Core Classes

### AgentHostBuilder

Main entry point for creating agent hosts.

### Agent

Represents a configured AI agent.

### FunctionRegistry

Manages callable tools/functions.
