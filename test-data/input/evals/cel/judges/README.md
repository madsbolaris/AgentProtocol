# CEL Judge Validation Tests

CEL expressions for validating and combining judge results.

## Test Files

- **55-cel-judge-details.xml** - Access judge details and metadata
- **56-cel-all-judges-pass.xml** - Require all judges to pass
- **57-cel-any-judge-passes.xml** - Require at least one judge to pass

## Purpose

Tests CEL's ability to:
- Access judge result details
- Combine multiple judge outcomes
- Implement AND/OR logic across judges
- Extract judge-specific information
