# Domain-Specific Tests

Evaluation tests organized by knowledge domain and task type.

## Subdirectories

### math/
Mathematical reasoning and computation tests.

### code/
Code generation, analysis, and data extraction tests.

### language/
Multi-language support, translation, and instruction following tests.

### creative/
Creative tasks including fact verification and comparison tests.

## Purpose

These tests assess domain-specific capabilities:
- Mathematical problem solving
- Code understanding and generation
- Language translation and instruction following
- Creative and analytical tasks
- Domain-specific reasoning
