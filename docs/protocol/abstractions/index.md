# Abstractions

Base models, types, and interfaces for the Agent Protocol.

## Overview

This section contains all the data models, base types, and interfaces used throughout the Agent Protocol.

## Categories

- **Base Types** - Abstract base classes and interfaces
- **Core Models** - Thread, Run, Message, Agent
- **Content Types** - Text, Image, Audio, Video, Function calls, etc.
- **Events** - Lifecycle events (RunCreated, MessageCreated, etc.)
- **Configuration** - AgentModel, RunOptions, ModelOptions, etc.
