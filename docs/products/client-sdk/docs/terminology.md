# Terminology

Key terms and concepts used in the Client SDK.

## Agent

An AI assistant that can converse, use tools, and process multiple content types.

## Thread

A conversation session with message history.

## Run

A single execution of an agent within a thread.

## Tools

Functions that agents can call to take actions or retrieve information.

## Streaming

Receiving responses piece-by-piece as they're generated.

## Ephemeral

Temporary, not persisted (opposite: persistent).
