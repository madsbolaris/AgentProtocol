# Special Content Tests

Tests for special characters, Unicode, and unusual content handling.

## Test Files

- **29-url-extraction.xml** - URL parsing and extraction
- **49-table-generation.xml** - Table generation and formatting
- **50-edge-case-unicode.xml** - Unicode and special character handling

## Purpose

Validates:
- Special character handling
- Unicode support
- URL parsing and validation
- Complex formatting (tables)
- Non-ASCII content
- Emoji and symbol support
