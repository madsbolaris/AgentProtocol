# Edge Case Tests

Tests for handling edge cases, errors, limits, and special scenarios.

## Subdirectories

### empty/
Empty response and null content handling.

### errors/
Error handling, refusals, and failure scenarios.

### limits/
Boundary conditions, timeouts, and constraint testing.

### special/
Special characters, Unicode, and unusual content handling.

## Purpose

These tests ensure robust handling of:
- Boundary conditions
- Error scenarios
- Empty or missing data
- Special characters and encodings
- System limits and timeouts
