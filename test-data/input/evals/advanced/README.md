# Advanced Features Tests

Tests for advanced capabilities including streaming, reasoning, and quality assessment.

## Subdirectories

### streaming/
Streaming response and rate limiting tests.

### reasoning/
Advanced reasoning including thinking processes and chain-of-thought.

### quality/
Quality assessment including citations, disambiguation, and summarization.

## Purpose

These tests validate:
- Streaming capabilities
- Complex reasoning patterns
- Quality metrics and assessment
- Advanced interaction patterns
