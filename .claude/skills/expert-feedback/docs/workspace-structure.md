# Expert Feedback Workspace Structure

All expert feedback sessions use this standardized workspace structure.

## Directory Layout

```
.workspace/YYYY/MM/DD/expert-feedback-{topic}/
├── state.json                        # Session state and convergence
├── iteration-1/
│   ├── experts/
│   │   ├── {expert}/
│   │   │   ├── review-{expert}.md   # Expert review (markdown, source of truth)
│   │   │   ├── state-{expert}.json  # Parsed from review.md (auto-generated)
│   │   │   ├── questions-{expert}.json # Parsed from review.md (auto-generated)
│   │   │   └── scripts/             # Expert-created analysis scripts
│   │   │       ├── analyze_*.py
│   │   │       └── outputs/         # Script outputs
│   │   │           └── *.json
│   │   └── [other experts...]
│   ├── synthesized.md              # Synthesized feedback
│   ├── questions.json               # Synthesized questions for user
│   └── qa-answers.json              # User answers
├── iteration-2/                      # Refinement iteration (delta-only)
│   ├── experts/
│   │   └── [same structure as iteration-1]
│   ├── synthesized.md              # Updated synthesizion
│   └── qa-answers.json
├── artifacts/
│   ├── draft-adr.md                 # Draft ADR (review mode)
│   ├── draft-plan.md                # Draft implementation plan (improve mode)
│   ├── draft-architecture.md        # Draft architecture plan (create mode)
│   └── final-*.md                   # User-approved final artifacts
└── logs/
    ├── spawn-experts.log
    ├── synthesizion.log
    └── artifact generation.log
```

## File Types

### Markdown Files (.md)
Expert-authored content in human-readable format. These are the **source of truth**.

- `review-{expert}.md` - Expert's review in markdown format
- `synthesized.md` - Synthesized feedback from all experts
- `draft-*.md` - Draft artifacts generated by artifact generation
- `final-*.md` - User-approved final artifacts

### JSON Files (.json)
Auto-generated by `parse_markdown.py` from markdown files. **Never edited manually.**

- `state-{expert}.json` - Parsed expert review data
- `questions-{expert}.json` - Parsed expert questions
- `state.json` - Overall workflow state
- `questions.json` - Synthesized questions for user
- `qa-answers.json` - User answers to questions

### State Files
- `state.json` - Tracks iteration number, convergence percentage, expert sessions, current phase
- `questions.json` - Synthesized questions from all experts (no limit on question count)
- `qa-answers.json` - User's answers to questions

## Iteration Flow

### Iteration 1 (Initial Reviews)
1. Experts write **complete** reviews in markdown
2. Parser extracts JSON from markdown
3. Synthesizion merges all expert feedback
4. Questions extracted and presented to user
5. User answers questions via web UI

### Iteration 2+ (Delta Refinements)
1. Experts write **delta-only** refinements (what changed)
2. Parser extracts delta JSON
3. Synthesizion merges updated feedback
4. New questions extracted if any
5. Process repeats until convergence or user finalizes

### Artifact Generation
1. All iterations merged to reconstruct full context
2. Final artifact generated based on mode:
   - **review**: Architecture Decision Record (ADR)
   - **improve**: Implementation Plan
   - **create**: Architecture + Implementation Plan
3. Experts review draft artifact
4. User approves or requests changes

## Best Practices

### For Experts
1. **Write markdown files only** - JSON is auto-generated
2. **Use proper workspace paths** - Follow the structure above
3. **Create analysis scripts** - Put them in `scripts/` folder
4. **Save script outputs** - Put them in `scripts/outputs/`
5. **Reference your work** - Link to scripts and outputs in review

### For Scripts
1. **Read state from state.json** - Single source of truth
2. **Never modify JSON files manually** - They're auto-generated
3. **Follow workspace paths** - Use `workspace_utils.py`
4. **Log to logs/ directory** - Keep workspace organized

### For Users
1. **Don't edit workspace files manually** - Let the workflow manage them
2. **Use web UI for Q&A** - Don't edit qa-answers.json directly
3. **Workspace is permanent** - Safe to resume even days later
4. **Artifacts are in artifacts/** - Find final outputs there

## Mode-Specific Outputs

### Review Mode (ADR)
- **Output:** `artifacts/final-adr.md`
- **Format:** Architecture Decision Record
- **Sections:** Context, Decision, Consequences, Alternatives

### Improve Mode (Implementation Plan)
- **Output:** `artifacts/final-plan.md`
- **Format:** Detailed implementation plan
- **Sections:** Overview, Phases, Tasks, Testing, Rollback

### Create Mode (Architecture + Plan)
- **Output:** `artifacts/final-architecture.md` + `artifacts/final-plan.md`
- **Format:** Architecture document + Implementation plan
- **Sections:** System design, components, data flow, implementation steps
