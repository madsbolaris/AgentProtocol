# Echo Bot Integration Test Results

This directory contains **language-agnostic** results from echo bot integration tests using the Agent Protocol client. These golden files are shared across all SDK implementations (Python, .NET, etc.).

## Directory Structure

```
echobot/
├── json/        # Results with format=json query parameter
├── xml/         # Results with format=xml query parameter
├── streaming/   # Results from streaming pattern (future)
└── *.md         # Documentation
```

## 🔑 Key Concept: Shared Results

**These results are used by ALL language implementations.**

- ✅ Python tests generate/validate against these files
- ✅ .NET tests generate/validate against these files
- ✅ Future implementations (TypeScript, Java, etc.) will use the same files

**Why?** The echo bot behavior is identical regardless of which client SDK is used. Sharing results ensures:
- Single source of truth
- Cross-language validation
- Protocol compliance
- No duplication

## Test Coverage

The integration tests cover all input files from `test-data/input/`:

### Test Patterns

1. **JSON Format** (`json/`)
   - Uses `?format=json` query parameter (default)
   - **Results format**: JSON RunWaitResponse with run status and output
   - Returns complete run information including runId, threadId, input, output, timestamps
   - Example: `POST /runs/wait?format=json` or `POST /runs?format=json`

2. **XML Format** (`xml/`)
   - Uses `?format=xml` query parameter
   - **Results format**: XML Thread documents with message elements
   - Returns thread-id, status, created-at attributes and message children
   - Example: `POST /runs/wait?format=xml` or `POST /runs?format=xml`

3. **Streaming Pattern** (`streaming/`)
   - Tests streaming responses (when implemented)
   - Captures incremental response chunks
   - Currently skipped - awaiting streaming support

## Running Tests

### Prerequisites

**Choose ONE echo bot implementation to test against:**

#### Option 1: Python Echo Bot
```bash
cd python/samples/agents/echo-bot
python src/main.py
```

#### Option 2: .NET Echo Bot
```bash
cd dotnet/samples/agents/EchoBot
dotnet run
```

#### Option 3: TypeScript Echo Bot
```bash
cd typescript/samples/echo-bot
npm install
npm run build
npm start
```

**Verify echo bot is running:**
```bash
curl http://localhost:3978/health
# Should return: OK
```

**Note:** All three echo bots support the same Agent Protocol endpoints:
- `POST /runs` - Create run
- `POST /runs/wait` - Create and wait for completion
- `POST /runs/stream` - Create and stream results (SSE)
- `GET /runs/{runId}/stream` - Reconnect to existing run stream

### Run Integration Tests

```bash
cd python/microsoft-agents-protocol

# Run all echo bot tests
pytest tests/test_echobot_integration.py -v

# Run specific pattern
pytest tests/test_echobot_integration.py::TestEchoBotXmlPattern -v
pytest tests/test_echobot_integration.py::TestEchoBotWaitPattern -v

# Run single test file
pytest tests/test_echobot_integration.py::TestEchoBotXmlPattern::test_echobot_xml_pattern[03-user-text-only.xml] -v

# Run and show print output
pytest tests/test_echobot_integration.py -v -s
```

### Manual Test

Run the manual test script:

```bash
cd python/microsoft-agents-protocol/tests
python test_echobot_integration.py
```

## Result Format

### Wait Pattern Results (JSON)

The `json/` directory contains JSON result files from `runs.create_and_wait()` with:

```json
{
  "run_id": "run_abc123",
  "agent_id": "echo-agent",
  "status": "completed",
  "input": [
    {
      "role": "user",
      "contents": [{"text": "What's the weather like in Seattle?"}]
    }
  ],
  "output": [
    {
      "role": "assistant",
      "contents": [{"text": "You said: What's the weather like in Seattle?"}]
    }
  ],
  "created_at": "2026-02-07T10:00:00Z",
  "completed_at": "2026-02-07T10:00:01Z",
  "usage": {
    "input_tokens": 10,
    "output_tokens": 12,
    "total_tokens": 22
  }
}
```

### XML Pattern Results (XML)

The `xml/` directory contains XML response files with thread messages:

```xml
<?xml version='1.0' encoding='utf-8'?>
<thread thread-id="thread_001" status="active" created-at="2026-02-07T10:00:00Z">
  <agent message-id="msg_001" created-at="2026-02-07T10:00:01Z">
    <text audience="user">Echo: Your message content</text>
  </agent>
</thread>
```

## Regenerating Golden Files

The golden files in `json/` are generated by integration tests. To regenerate them:

1. **Start the echo bot**:
   ```bash
   # Python
   cd python/samples/agents/echo-bot && python src/main.py

   # Or .NET
   cd dotnet/samples/agents/EchoBot && dotnet run
   ```

2. **Run integration tests in record mode**:
   ```bash
   cd python/microsoft-agents-protocol
   pytest tests/test_echobot_integration.py --record-golden
   ```

3. **Review the generated files**:
   ```bash
   ls -la test-data/results/echobot/json/
   ```

4. **Commit the golden files** once verified:
   ```bash
   git add test-data/results/echobot/json/*.json
   git commit -m "Update JSON format golden files"
   ```

**Note**: The `xml/` directory golden files are already committed. Only `json/` JSON files need to be regenerated.

## Expected Behavior

For each input message, the echo bot should:

1. **Accept** the message via Agent Protocol API
2. **Process** the message (extract text content)
3. **Respond** with a message starting with "You said: " followed by the input text
4. **Return** a valid `Run` object with status and output

Example:

**Input**:
```xml
<user message-id="msg_001" user-id="user_alice_123">
  <text>What's the weather like in Seattle?</text>
</user>
```

**Expected Output**:
```json
{
  "role": "assistant",
  "contents": [
    {"text": "You said: What's the weather like in Seattle?"}
  ]
}
```

## Troubleshooting

### Echo Bot Not Running

```
Error: httpx.ConnectError
```

**Solution**: Start the echo bot server (see Prerequisites)

### Input File Not Found

```
pytest.skip: Input directory not found
```

**Solution**: Ensure you're running from the correct directory and `test-data/input` exists

### XML Parsing Errors

```
Warning: Could not parse XML to ChatMessage
```

**Solution**: Check that the XML file matches the expected schema. Some complex messages may need enhanced parsing logic.

## CI/CD Integration

These tests can be integrated into CI/CD:

```yaml
# .github/workflows/echobot-tests.yml
name: Echo Bot Integration Tests

on: [push, pull_request]

jobs:
  integration-tests:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3

      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'

      - name: Install dependencies
        run: |
          pip install -e python/microsoft-agents-protocol[dev]
          pip install -e python/microsoft-agents-xml

      - name: Start Echo Bot
        run: |
          python python/samples/agents/echo-bot/src/start_server.py &
          sleep 5  # Wait for server to start

      - name: Run Integration Tests
        run: |
          pytest python/microsoft-agents-protocol/tests/test_echobot_integration.py -v

      - name: Upload Results
        uses: actions/upload-artifact@v3
        with:
          name: echobot-test-results
          path: test-data/results/echobot/
```
