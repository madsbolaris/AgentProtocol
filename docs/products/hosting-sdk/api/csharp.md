# C# API Reference

Complete API documentation for C# Hosting SDK.

## Overview

The C# Hosting SDK provides a type-safe, fluent API for building AI agents.

---

## Installation

=== "C#"
    ```bash
    dotnet add package Microsoft.Agents.Hosting
    ```

---

## Core Classes

### AgentHostBuilder

Main entry point for creating agent hosts.

### Agent

Represents a configured AI agent.

### FunctionRegistry

Manages callable tools/functions.
