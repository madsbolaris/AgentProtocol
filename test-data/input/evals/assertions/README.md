# Assertion Tests

Tests focused on various assertion types and validation mechanisms.

## Test Files

- **08-multiple-asserts.xml** - Multiple assertions per expectation
- **10-numeric-comparison.xml** - Numeric value comparisons
- **11-repeat-test.xml** - Repeated test execution with consistent results
- **16-length-assertion.xml** - Response length validation

## Purpose

These tests demonstrate:
- Multiple assertion combinations
- Numeric validation
- Test repeatability and consistency
- Length-based constraints
- Assertion chaining
