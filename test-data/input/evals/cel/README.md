# CEL (Common Expression Language) Tests

Evaluation tests using CEL expressions for assertions and validation.

## Subdirectories

### operators/
Tests for CEL boolean and numeric operators.

### complex/
Complex CEL expressions including score ranges and conditional logic.

### judges/
CEL-based judge validation and combination logic.

### math/
Mathematical operations and edge case handling in CEL.

## Purpose

These tests demonstrate CEL's capabilities for:
- Boolean and numeric comparisons
- Complex conditional expressions
- Judge result aggregation
- Mathematical computations
- Edge case handling

## CEL Overview

CEL (Common Expression Language) is a non-Turing complete expression language designed for fast, safe evaluation. It's used in the evaluation system for flexible assertion logic without the security risks of full scripting languages.
