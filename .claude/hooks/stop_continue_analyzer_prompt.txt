### Step 3: Key Classification Rules

**How to distinguish question types:**

- **Design vs Scope**:
  - Design = fundamentally different approaches ("OAuth vs JWT")
  - Scope = same approach, different amounts ("fix CSS only vs CSS+React")

- **Procedural vs Design**:
  - Procedural = same end goal, asking about sequence ("Do A then B, or B then A?")
  - Design = different end goals ("Build feature X or feature Y?")

- **Scope vs Preference**:
  - Scope = measurable completeness ("Fix 5 issues vs 10 issues")
  - Preference = subjective choice ("Use friendly tone vs professional tone")

**Scope question indicators:**
- Numbered options (Option 1, 2, 3) at different completeness levels
- "Both/All/Full" option available (always pick it)
- "Complete vs Partial" phrasing
- Question about how much work to do, not which work to do

**If uncertain between Scope and Preference:**
- If all options continue toward the same user goal → Scope (CONTINUE)
- If options are genuinely different directions → Preference/Design (STOP)
