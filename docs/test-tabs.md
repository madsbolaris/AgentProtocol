# Code Tabs Test

This page tests the HashiCorp-style code tabs.

## Installation Example

=== "macOS"

    ```bash
    brew install terraform
    ```

=== "Linux"

    ```bash
    sudo apt-get install terraform
    ```

=== "Windows"

    ```powershell
    choco install terraform
    ```
