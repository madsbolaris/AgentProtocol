# Basic Evaluation Tests

This directory contains fundamental evaluation test cases that demonstrate core functionality of the evaluation system.

## Test Files

- **01-simple-text-expect.xml** - Simple text expectation with exact match validation
- **02-multiple-expects.xml** - Multiple expectations in a single evaluation thread
- **03-with-run-config.xml** - Evaluation with custom run configuration settings
- **09-json-output-expect.xml** - JSON output validation and structure checking

## Purpose

These tests establish the baseline functionality for:
- Basic text matching and validation
- Multiple assertion handling
- Configuration management
- Structured output validation

## Usage

These tests serve as the foundation for understanding the evaluation system and should pass consistently across all implementations (.NET, Python, TypeScript).
