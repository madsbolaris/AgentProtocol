# Python API Reference

Complete API documentation for Python Hosting SDK.

## Overview

The Python Hosting SDK provides a type-safe, fluent API for building AI agents.

---

## Installation

=== "Python"
    ```bash
    pip install microsoft-agents-hosting
    ```

---

## Core Classes

### AgentHostBuilder

Main entry point for creating agent hosts.

### Agent

Represents a configured AI agent.

### FunctionRegistry

Manages callable tools/functions.
