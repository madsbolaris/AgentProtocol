# Content Type Tests

Evaluation tests for various content types and multimodal inputs.

## Test Files

- **14-multimodal-input.xml** - Multimodal input handling (text, images, etc.)
- **19-adaptive-card-output.xml** - Adaptive card generation and validation
- **20-suggested-actions.xml** - Suggested actions and quick replies
- **31-document-reference.xml** - Document reference and citation handling
- **32-audio-transcription.xml** - Audio content transcription
- **33-video-analysis.xml** - Video content analysis and understanding

## Purpose

Tests support for:
- Multimodal content (text, image, audio, video)
- Rich card formats (Adaptive Cards)
- Interactive elements (suggested actions)
- Document and citation handling
- Media transcription and analysis
