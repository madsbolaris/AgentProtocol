# Text Judge Tests

Text-based evaluation judges for content validation.

## Test Files

- **05-llm-judge.xml** - LLM-based semantic similarity judge
- **06-regex-judge.xml** - Regular expression pattern matching
- **23-case-insensitive-match.xml** - Case-insensitive text matching

## Judge Types

- **LLM Judge**: Uses language models to assess semantic similarity
- **Regex Judge**: Pattern-based validation for structured content
- **Case-Insensitive**: Flexible text matching without case sensitivity
