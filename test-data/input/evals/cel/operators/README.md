# CEL Operator Tests

Tests for CEL boolean and numeric operators.

## Test Files

- **51-cel-boolean-operators.xml** - Boolean logic operators (AND, OR, NOT)
- **52-cel-numeric-comparisons.xml** - Numeric comparison operators (>, <, >=, <=, ==)

## Purpose

Validates CEL operator functionality including:
- Boolean logic operations
- Numeric comparisons
- Operator precedence
- Type handling
