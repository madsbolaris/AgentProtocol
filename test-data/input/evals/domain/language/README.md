# Language and Instruction Tests

Tests for multi-language support, translation, and instruction following.

## Test Files

- **30-multi-language.xml** - Multi-language content handling
- **39-instruction-following.xml** - Following complex instructions
- **40-error-recovery.xml** - Error recovery and correction
- **48-translation-test.xml** - Language translation accuracy

## Purpose

Validates:
- Multi-language understanding
- Translation quality and accuracy
- Instruction comprehension and execution
- Error handling and recovery
- Cross-language capabilities
