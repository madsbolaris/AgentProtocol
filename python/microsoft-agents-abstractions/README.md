# Microsoft Agents Abstractions (Python)

Core abstractions and message models for the Microsoft Agents Framework.

## Overview

This package provides the foundational message models and content types for the Microsoft Agents Protocol. These models are **autogenerated from TypeSpec definitions** to ensure consistency across .NET, Python, and TypeScript implementations.

## Installation

```bash
pip install microsoft-agents-abstractions
```

## Core Models

- **ChatMessage** - Base message model with polymorphic role types
- **SystemMessage**, **DeveloperMessage**, **UserMessage**, **AgentMessage**, **ToolMessage**, **ChannelMessage**
- **AIContent** - Polymorphic content base class
- **TextContent**, **ImageContent**, **AudioContent**, **VideoContent**, **FileContent**
- **FunctionCallContent**, **FunctionResultContent**
- And many more content types...

## Usage

```python
from microsoft.agents import ChatMessage, UserMessage, TextContent

# Create a user message
message = UserMessage(
    message_id="msg_123",
    contents=[
        TextContent(text="Hello, world!")
    ],
    user_id="user_789"
)
```

## Code Generation

This package is generated from TypeSpec definitions located in `/specs/typespec/messages.tsp`.

To regenerate the code:
```bash
cd scripts/generation
./generate-python.sh
```
