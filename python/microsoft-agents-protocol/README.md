# Microsoft Agents Protocol (Python)

A simple extension package that adds Agent Protocol routes to your M365 Agents SDK application in one line of code.

## Installation

```bash
pip install microsoft-agents-protocol
```

## Usage

```python
from aiohttp.web import Application
from microsoft.agents.hosting.core import AgentApplication
from microsoft.agents.protocol import add_agent_protocol_routes

# Create your agent application
agent_app = AgentApplication(...)

# Create aiohttp app
app = Application()

# Add Agent Protocol routes in one line!
add_agent_protocol_routes(app, agent_app)
```

## What Routes Are Added?

The `add_agent_protocol_routes()` function adds the following endpoints:

- **`GET /health`** - Health check endpoint
- **`POST /runs`** - Create a new run
- **`POST /runs/wait`** - Create a run and wait for completion
- **`POST /runs/stream`** - Create a run and stream results
- **`GET /runs/{runId}/stream`** - Stream a specific run

## Configuration

You can customize the endpoint paths:

```python
add_agent_protocol_routes(
    app,
    agent_app,
    health_path="/api/health",  # Custom health endpoint
    runs_path="/api/runs"        # Custom runs base path
)
```
