# Tool Call Judge Tests

Evaluation tests for validating function/tool call behavior.

## Test Files

- **04-tool-call-expect.xml** - Basic tool call expectation and validation
- **15-complex-tool-sequence.xml** - Multi-step tool call sequences
- **22-parallel-tool-calls.xml** - Concurrent/parallel tool execution

## Purpose

These tests validate:
- Tool call structure and arguments
- Sequential tool execution flows
- Parallel tool invocation handling
- Tool result validation
